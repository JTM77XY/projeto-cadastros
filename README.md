# Sistema de gerenciamento de estoque com página de login

## Descrição
 O projeto é um sistema para gerenciar produtos de estoque com uma tela de login para acessar esse sistema. 

 Tela de login: o usuario digita o nome ou email e uma senha para acessar o sistema de gerenciamento de estoque.

 Sistema de gerenciamento de estoque: o site permite cadastrar, pesquisar e escluir produtos do sistema.

 esse projeto foi pensado para uma loja de games que precisa gerenciar o seu estoque de produtos.

## Instruções de instalação e uso
 Instale o visual estudio code e a estenção live server.

 use a estenção live server para abrir os dois arquivos html que correspondem as duas páginas do projeto em um navegador.
